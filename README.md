# Portafolio web — Isaac David Polo Molina

Sitio estático hecho con HTML y CSS, preparado para publicar en Netlify desde la raíz de un repositorio GitHub.

## Archivos
- `index.html`: estructura y contenido del portafolio.
- `style.css`: estilos, diseño adaptable a móviles y efectos visuales.

## Antes de publicar
Abre `index.html` y reemplaza estos valores por tus datos reales:
- `TU_USUARIO` por tu nombre de usuario de GitHub.
- `TU_CORREO` por tu correo de contacto.
- `URL_DE_TU_LINKEDIN` por la URL de tu perfil de LinkedIn. Si no tienes LinkedIn, puedes quitar ese enlace.
- Cambia el enlace del repositorio de SurtiEsquina cuando tengas la URL real.

## Publicar en Netlify
1. Sube `index.html`, `style.css` y `README.md` a la **raíz** de tu repositorio de GitHub.
2. En Netlify, selecciona **Add new site / Import an existing project** y conecta GitHub.
3. Selecciona el repositorio.
4. Como es una web estática sin proceso de compilación, deja **Build command** vacío y usa `.` como **Publish directory** (o deja el directorio raíz si Netlify lo permite).
5. Pulsa **Deploy**. Netlify volverá a publicar los cambios cada vez que actualices la rama conectada.

Los iconos de tecnologías se cargan desde skillicons.dev y las fuentes desde Google Fonts, por lo que requieren conexión a internet.
